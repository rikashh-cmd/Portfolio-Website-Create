RESPONSIVE INTERACTIVE PORTFOLIO
================================

Files
-----
index.html  - Website structure and content
style.css   - Responsive design, dark blue gradient, animations and themes
script.js   - Navigation, theme switch, project modals, reveal animations and GitHub API

How to run
----------
1. Extract the ZIP file into a folder.
2. Open index.html in a modern web browser.
3. For best results, open the folder in Visual Studio Code and use the Live Server extension.
4. An internet connection is needed for Google Fonts and live GitHub repository loading.

Personalise before submitting
------------------------------
1. In index.html, confirm your name, education, skills, projects and contact links.
2. Replace the LinkedIn homepage URL with your own LinkedIn profile URL.
3. Update the project cards and descriptions to match your actual completed work.
4. The GitHub API username is set to "rikashh-cmd" in script.js. Change it if needed.
5. Add screenshots and repository links for your real coursework projects if available.

Coursework features covered
---------------------------
- Semantic HTML5 elements: header, nav, main, section, article and footer
- Responsive layout using CSS Grid, Flexbox and media queries
- Smooth scrolling and mobile navigation
- Interactive project detail dialog
- Public GitHub API integration for dynamic repository data
- CSS variables and theme toggle
- Google Fonts, transitions, animations and visual filters
- Accessibility basics: skip link, labels, ARIA states, keyboard-friendly dialog and reduced-motion support

Note
----
This is a front-end portfolio template. The project descriptions are sample summaries of learning/coursework areas;
make sure they accurately reflect what you personally completed before publishing or submitting.
